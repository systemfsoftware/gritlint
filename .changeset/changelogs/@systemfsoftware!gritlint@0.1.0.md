# @systemfsoftware/gritlint@0.1.0

The first release from systemfsoftware/gritlint. gritlint runs GritQL rule packs over a repository's config files. It ships as this repository's Nix flake, `packages.<system>.gritlint`, sandboxed by bubblewrap, and as an npm-style tarball, `gritlint-tarball`, holding static binaries for linux-x64 and linux-arm64 and a node launcher. It was imported from the systemfsoftware monorepo at `df908ddfe497e53c1c03b92519a96c913c441a58`.
